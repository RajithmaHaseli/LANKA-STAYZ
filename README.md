# Lanka Stayz – Accommodation Booking Website

## Project Overview

Lanka Stayz is a responsive accommodation booking website prototype designed to help users discover and explore accommodation options across Sri Lanka. Users can browse properties, filter accommodations by destination, view property details, and submit booking requests through a user-friendly interface.

## Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- React Icons
- Git and GitHub
- Vercel (Deployment)

## Key Features

- Responsive homepage with navigation and destination search.
- Accommodation listings featuring sample properties across Sri Lanka.
- Destination-based property filtering.
- Property details with images, descriptions, prices, and amenities.
- Booking request form with input validation.
- Booking request confirmation message.
- Responsive layouts for desktop, tablet, and mobile devices.
- Footer with contact information and social media links.

## Installation and Setup Instructions

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the Repository

    git clone https://github.com/RajithmaHaseli/LANKA-STAYZ.git

### 2. Navigate to the Project Directory

    cd lanka-stayz

### 3. Install Dependencies

    npm install

### 4. Run the Development Server

    npm run dev

### 5. Access the Application

Open the local development URL provided in the terminal:

    http://localhost:5173

## Production Build

To create a production-ready build:

    npm run build

To preview the production build locally:

    npm run preview

## Incomplete Features and Limitations

This project is developed as a frontend prototype. The following features are not implemented:

- Backend server and database integration.
- Real-time accommodation availability checking.
- Actual booking request submission and storage.
- Online payment gateway integration.
- Live property data and management.

Property information is currently displayed using sample data. The booking form provides frontend validation and a confirmation message for demonstration purposes only. It does not create an actual reservation.
