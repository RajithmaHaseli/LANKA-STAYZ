# LANKA STAYZ – Accommodation Booking Website 💙

## Project Overview
Lanka Stayz is a responsive accommodation booking website prototype designed to help users discover and explore places to stay in Sri Lanka.
The website allows visitors to browse accommodation options, filter properties by destination, view property details, and submit booking requests through a simple booking form.
This project was developed as part of a Web Developer Technical Assessment.

## Features
### 1. Homepage
- Responsive navigation bar.
- Hero section with an automatic image slider and destination search form.
- Search fields for destination, check-in date, check-out date, and number of guests.
- Featured accommodation listings.
- About Us section.
- Footer with contact information and social media icons.

### 2. Accommodation Listings
- Displays sample properties across popular destinations in Sri Lanka.
- Property images, names, locations, and nightly prices in LKR.
- Displays accommodation types and maximum guest capacity.
- Destination filtering.
- View Details option for each property.

### 3. Property Details
- Detailed property information.
- Multiple property images.
- Accommodation description.
- Available amenities, including Wi-Fi, swimming pool, air conditioning, and parking.
- Nightly pricing and maximum guest capacity.
- Book Now option.

### 4. Booking Request
- Separate booking request page / flow.
- Guest name, email address, and contact number fields.
- Check-in and check-out date selection.
- Guest count selection.
- Required-field validation.
- Booking request confirmation message.

### 5. Responsive Design
- Desktop, tablet, and mobile-friendly layouts.
- Responsive navigation and property cards.
- Consistent styling and user-friendly interface.

## Technologies Used
- **React.js** – Frontend development.
- **Vite** – Development server and build tool.
- **JavaScript (ES6+)** – Application functionality.
- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **React Icons** – Social media and interface icons.
